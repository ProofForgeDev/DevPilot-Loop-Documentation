## 半决赛前必须完成的改动

### P0: 致命缺陷 (每个 -3~5 分)
1. **真实 LLM 集成** 
   - 接入 OpenRouter 免费 API 或本地 Ollama
   - 替换 rule-engine fallback 为真实推理
   - 预计工作量: 半天

2. **真实 AgentTeams SDK**
   - 替换 FastAPI mock 为 agentteams SDK
   - 预计改动: <200 行
   - 预计工作量: 1天

3. **真实 GitHub 仓库**
   - 创建 ProofForgeDev/DevPilot-Loop 正式仓库
   - 推送所有代码，建立 commit 历史
   - 添加 README, CONTRIBUTING, LICENSE
   - 预计工作量: 2小时

4. **真实终端截图**
   - 在真实容器中运行系统
   - 使用 screen/capture 工具录制真实终端
   - 替换 PIL 生成的截图
   - 预计工作量: 3小时

### P1: 重要改进 (每个 -1~2 分)
5. **Prometheus 指标端点**
   - 添加 /metrics HTTP 端点
   - 暴露请求数、延迟、成功率等指标
   - 预计工作量: 半天

6. **Cloud Skills 集成**
   - 实现阿里云 Skills 调用
   - 展示与云平台的集成能力
   - 预计工作量: 1天

7. **Nacos 配置管理**
   - 接入 Nacos 动态配置
   - 支持运行时配置热更新
   - 预计工作量: 半天

### P2: 加分项 (每个 +0.5~1 分)
8. **AgentLoop 可观测性**
   - 集成 AgentLoop 框架
   - 提供更丰富的 traces 和 metrics
   - 预计工作量: 1天

9. **评估数据集**
   - 构建 SWE-bench lite 子集
   - 记录 golden/bad cases
   - 自动化评估脚本
   - 预计工作量: 2天

10. **社区运营计划**
    - 制定贡献者指南
    - 设计 milestone 路线

    - 预计工作量: 半天
