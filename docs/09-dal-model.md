# DAL：DevPilot Autonomy Level 分级模型

> 参考 ISO/SAE 自动驾驶分级标准（SAE J3016）的写法风格，
> 为研发 Agent 自主性定义行业统一标尺。

---

## 分级定义

| 级别 | 名称 | 定义 | 人机分工 | 技术判据（3 条） | 当前状态 |
|------|------|------|---------|-----------------|---------|
| **DAL-1** | 辅助定位 | Agent 辅助人类定位问题，人类执行修复 | 人：改码、测试、发布。Agent：找问题、给建议 | ①根因候选输出 ②证据链呈现 ③人确认后才执行 | ✅ PoC 已实现 |
| **DAL-2** | 自主修复 | Agent 自主修复与测试，人审批关键节点 | 人：审批 push/发布。Agent：定位→改→测 | ①自动生成 patch ②自动执行测试 ③审批流完整 | ✅ PoC 已实现 |
| **DAL-3** | 自主闭环 | Agent 自主修复+验证+灰度，人抽检 | 人：抽检。Agent：全链路执行 | ①灰度自动化 ②回滚自动化 ③抽检机制 | 🎯 复赛目标 |
| **DAL-4** | 多项目并行 | Agent 跨项目自主运维，人定策略 | 人：定策略。Agent：多项目并行 | ①多租户隔离 ②策略引擎 ③资源调度 | 决赛愿景 |
| **DAL-5** | 全自动闭环 | Agent 全自主，人定目标 | 人：定目标。Agent：全自主 | ①目标自分解 ②自演进 Skill ③零人工介入 | 长期愿景 |

---

## DAL 演进路线图

| 演进 | 所需技术突破 | 预计时间 | 关键风险 |
|------|------------|---------|---------|
| DAL-2 → DAL-3 | 灰度自动化（对接真实 K8s）+ 回滚自动化 + 抽检机制 | 复赛（2026-09） | 生产安全 |
| DAL-3 → DAL-4 | 多租户隔离 + 策略引擎 + 资源调度 | 2027-H1 | 隔离与成本 |
| DAL-4 → DAL-5 | 目标自分解 + 自演进 Skill + 零人工 | 长期 | 可控性 |

---

## 类比说明

DAL 之于研发 Agent，正如 **L1–L5 之于自动驾驶**：

| 自动驾驶 | DevPilot Loop |
|---------|--------------|
| L1 辅助驾驶（定速巡航） | DAL-1 辅助定位 |
| L2 部分自动（车道保持+自适应巡航） | DAL-2 自主修复，人审批 |
| L3 有条件自动（特定场景自主） | DAL-3 自主闭环，人抽检 |
| L4 高度自动（限定区域无人驾驶） | DAL-4 多项目并行 |
| L5 完全自动（任何场景无人驾驶） | DAL-5 全自动闭环 |

**价值**：让行业有统一的自主性标尺，避免"全自动"的模糊营销，
让每个项目可以精确定位自己的自主级别。
